3. Schema Check

Kiem tra kieu du lieu cua tung cot:
dataset | column_name | dtype | non_null_count | null_count | null_pct | unique_count

Muc tieu:
- cot nao dang la string nhung dang le la numeric/date
- cot nao null nhieu
- cot nao cardinality qua cao
- cot nao co the la leakage/source signal cho label sau nay

Output:
- schema_check_df

________________________________________________________________________________

4. Missing value + distribution check

Truoc khi ket luan missing/placeholder, can xem phan phoi theo loai cot:
- categorical/boolean/binary: exact value counts
- numeric: summary va histogram bins
- string/category: top values va placeholder candidates

Placeholder can xem xet:
- (not set)
- not available in demo dataset
- unknown.unknown
- (not provided)
- unknown
- empty string

Chu y:
- Khong tu dong xem `(none)` la missing. Trong traffic medium, `(none)` co the la direct traffic hop le.

Output:
- column_role_df
- category_distribution_df
- category_distribution_summary_df
- numeric_summary_df
- numeric_histogram_df
- placeholder_candidate_df
- missing_value_check_df

Missing summary schema:
dataset | column | dtype | null_count | null_pct | placeholder_count | placeholder_pct | decision

7. Business Rule Check

Chi check raw data quality va source signal, khong check label cu.

Can kiem tra:
- transaction_revenue >= 0
- total_transaction_revenue >= 0
- totals_hits >= 0
- totals_pageviews >= 0
- totals_transactions >= 0
- visit_number >= 1
- revenue > 0 nhung totals_transactions = 0
- totals_transactions > 0 nhung revenue = 0

Output:
dataset | rule | issue_count | issue_pct | severity | decision

Chu y:
- Cac issue revenue/transaction o day la source signal consistency.
- Khong ket luan label imbalance trong buoc nay.

________________________________________________________________________________

8. Label Readiness Check

Muc tieu: kiem tra du lieu da san sang de tao label 30 ngay sau clean hay chua.

Can kiem tra:
- Co du key: fullVisitorId + visit_id
- Co session_date
- Co raw source signal revenue/transaction
- Raw revenue/transaction signal khong am
- Co bao nhieu session khong du future window 30 ngay

Rule future window:
- max_session_date = ngay lon nhat trong tung dataset
- session co full future window neu session_date <= max_session_date - 30 ngay
- session sau moc nay bi gan issue label_window_incomplete

Output:
- label_readiness_df
- label_source_signal_check_df

Schema label_readiness_df:
dataset | row_count | max_session_date | label_window_days | sessions_with_full_future_window | sessions_without_full_future_window | future_window_incomplete_pct
