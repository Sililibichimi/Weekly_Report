TASK 05: FEATURE ENGINEERING CHO BÀI TOÁN FUTURE 30D PURCHASE / REVENUE

Bài toán:
Tại mỗi session hiện tại của một user, dựa trên thông tin session hiện tại và lịch sử trước đó của user, dự đoán user có phát sinh mua hàng trong 30 ngày tiếp theo sau session hiện tại hay không, và nếu có thì tổng doanh thu trong 30 ngày tiếp theo là bao nhiêu.

Prediction time:
- Sau khi session hiện tại kết thúc.
- Vì vậy được phép dùng các thông tin hành vi của session hiện tại như hits, pageviews, time_on_site.
- Không được dùng các tín hiệu mua hàng/doanh thu của session hiện tại làm feature.

Grain của bảng feature:
- 1 dòng = 1 user tại 1 session hiện tại.
- Key = fullVisitorId + visit_id.

Input:
- data_pyspark_parquet/train_sessions_clean_30d_label
- data_pyspark_parquet/test_sessions_clean_30d_label
- data_pyspark_parquet/clean_30d_label_sessions_manifest.json

Output:
- data_pyspark_parquet/train_user_session_features_30d
- data_pyspark_parquet/test_user_session_features_30d
- data_pyspark_parquet/feature_engineering_manifest.json

Nguyên tắc quan trọng:
- Fit mọi quy tắc từ train only.
- Test chỉ apply/transform theo quy tắc đã fit từ train.
- Không dùng test để chọn feature, chọn threshold, chọn bucket, hay ra insight.
- Khi train/evaluate, chỉ dùng các dòng có has_full_30d_label_window = 1.

3. CHIẾN LƯỢC GIAI ĐOẠN FEATURE

Không đưa tất cả feature vào ngay từ đầu.
Chia thành 3 bộ feature:

- Feature Set V1 - Baseline nhỏ:
  Mục tiêu là chạy được pipeline end-to-end, để debug, khoảng 20-30 feature.

- Feature Set V2 - Extended:
  Thêm categorical chi tiết hơn và sparse flags nếu V1 đã ổn.

- Feature Set V3 - Advanced:
  Thêm rolling-window features và bucket features sau khi baseline đã chạy tốt.

Trong notebook đầu tiên chỉ bắt buộc build và validate V1.
V2/V3 có thể để dạng optional hoặc TODO.

5. XỬ LÝ NULL SAU KHI TẠO HISTORY

Session đầu tiên của user sẽ có nhiều history null.
Cần fill có chú ý:

- user_previous_sessions -> 0
- user_previous_total_revenue -> 0
- user_previous_purchase_count -> 0
- user_previous_avg_pageviews -> 0
- user_previous_avg_time_on_site -> 0
- user_previous_bounce_rate -> 0
- user_days_since_first_session -> 0
- user_days_since_previous_session -> -1
- user_days_since_previous_purchase -> -1

Tạo thêm flags:
- is_first_session = user_previous_sessions == 0
- has_previous_purchase = user_previous_purchase_count > 0

Nếu thêm 2 flags này vào V1 thì tổng feature tăng thêm 2 cột, vẫn chấp nhận được.
